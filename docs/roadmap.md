- V1 데이터·라벨 (작성됨)
- V2 현상 재현
- V3 채점기 표본 검수 (자체 제작 데이터가 우리 가설에 유리하게 짜였다는 의심에 답하는 근거)

## 알려진 문제

- 실험 전 점검 로그에서 S2가 `KeyError: 'rep'`로 멈춘 기록이 있다. Gemini 응답이 빈 상태에서 패키지가 0개일 때 생긴 것으로 보이며, 실제 응답이 들어온 뒤 다시 확인한다.
- 학습 작업(DQN, GNN)을 같은 PC에서 돌리면 메모리가 부족해 실험이 중단된다. 실험이 도는 동안은 학습을 돌리지 않는다.
- Qwen 캐시 `qwen_logits.jsonl`에는 S5·S6 분만 있고 S7·S1·S3 분은 비어 있다.
